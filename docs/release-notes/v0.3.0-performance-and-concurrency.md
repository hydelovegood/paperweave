# PaperWeave v0.3.0

Minor release focused on performance, connection hygiene, and optional parallel LLM stages.

## Improvements

- `summarize`, `qa`, and `run` now accept `--concurrency N` to run parallel LLM calls over a `ThreadPoolExecutor` (default remains sequential)
- `ingest` skips re-hashing files whose `path` + `size` + `mtime` match the registry, making repeat scans of unchanged libraries near-instant
- All database access now goes through `paperlab.storage.db.db_connection()`, which always closes connections and enables WAL, `busy_timeout`, and foreign-key enforcement
- New indexes on all foreign-key and lookup columns (`files`, `paper_files`, `sections`, `summaries`, `qa_items`, `external_links`, `citation_edges`, `task_runs`), applied automatically to existing databases
- Enrich provider clients share a `requests.Session` for connection reuse
- LLM calls now carry an explicit 300s request timeout instead of hanging indefinitely
- Dead code removed across `config`, `storage`, `parsing`, and `enrich` (unused `requests` imports, `ParsingSettings`, `ParseResult.errors`, `CORE_TABLE_NAMES`, test-only status helpers)

## Tooling

- GitHub Actions CI now runs `pytest` on Python 3.10 and 3.12 plus `ruff check src tests` on every push and PR
- `pip install -e .[dev]` installs the dev extras (pytest, ruff); ruff config lives in `pyproject.toml`
